# FiveM Inventory System

A lightweight, optimized inventory system for FiveM roleplay servers.

## Features

- Lightweight and optimized for performance
- Fully functional inventory system with item usage, dropping, and moving capabilities

## Requirements

- FiveM server
- ESX Framework

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Add `start inventory_system` to your server.cfg file.

## Usage

- Open inventory with the `/inventory` command.
- Use items by clicking on them in the inventory UI.
- Drop items by right-clicking on them in the inventory UI.
- Move items by dragging and dropping them in the inventory UI.

## Configuration

The script can be configured in the `config.lua` file. You can adjust settings such as:

- Maximum weight and slots in the inventory
- Default item weight
- Keys to open the inventory and hotbar
- Database settings
